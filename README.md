# DevX - Ajuste Rápido

Landing page do projeto **Ajuste Rápido**, uma funcionalidade conceitual para câmeras mobile que detecta a cena e aplica automaticamente as melhores configurações (ISO, abertura, foco, velocidade).

Projeto desenvolvido para a Sprint 2 de Web Development.
